# Thrive Performance Golf — Website Prototype

A responsive landing-page prototype inspired by the approved Thrive Performance visual concept.

## Structure
- `index.html` — landing page
- `styles.css` — responsive visual system
- `script.js` — lightweight interactions

## Preview
Open `index.html` locally or deploy as a static site. GitHub Pages, Firebase Hosting, Cloudflare Pages, Netlify, or Vercel can host it.
